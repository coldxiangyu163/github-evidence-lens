# 产品需求 v0.1

## 问题与用户

技术协作调研者、自我复盘者和开源社区维护者需要回答“这项具体贡献有哪些可核实的工程证据”，而不是把 stars、提交次数包装成人的分数。LLM 自由作文会误引；纯静态指标缺少上下文。

## 方案

CLI 收集机器事实，portable skill 指导宿主 Agent 逐步调查。人类提供目标领域和范围，Agent 选择代表样本、读 patch 与 review/CI、主动寻找反证；报告将机器数量与定性判断分开。

## v0.1 验收

1. public-only authored PR search，公开仓库元数据验证，分页去重，有界详情。
2. collect / inspect / report 可运行；参数严格校验，不执行目标代码，不写 GitHub。
3. evidence 稳定 ID、URL、时间、上下文、错误、覆盖率与预算；原子 JSON。
4. findings 必须引用现存 ID，状态/理由/反证/限制明确；三个安全输出格式，无个人分数。
5. 可移植 skill、rubric、schema、合成端到端、无网络 unittest、安装构建及 CI。

## 非目标

自动招聘决策、账号身份核验、私有贡献调查、AI 生成检测、万能能力排名、运行目标测试、远程服务/账号数据库、内置 LLM API。

## 发布边界

真实数据默认仅本地 artifacts；示例只用合成数据。发布仓库与真实公开烟测由操作者另行审核，不能把本机账户报告当示例自动上传。
